# Simple E-Commerce

A simple e-commerce web application built with Python Flask, SQLite, HTML, CSS, and JavaScript.

## Project Structure
- `app.py` - Flask application and routes
- `templates/` - HTML pages
- `static/` - CSS and JavaScript files
- `requirements.txt` - Python dependencies

## Getting Started
1. Clone the repo
2. `pip install -r requirements.txt`
3. `python app.py`
