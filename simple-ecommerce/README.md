# PyShop: Simple E-Commerce Website (Flask + SQLite)

## Run
```bash
python -m venv venv
venv\Scripts\activate        # Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

The database (shop.db) and 10 sample products are created automatically.

## Features
Product list, search, category filter, product page, cart (session),
checkout, orders saved to SQLite, orders list page.
